**A collaborative, SysML v2-native, web-first ecosystem for Model-Based Systems Engineering (MBSE).**

Mycelium connects engineers, models and tools so a team can build one shared, consistent system model. It builds on the experience of [CDP4-COMET](https://github.com/STARIONGROUP) and is built from the ground up on the OMG SysML v2 and KerML standards.

## The ecosystem

| Project | What it does |
| --- | --- |
| 🌸 [**Bloom**](https://github.com/mycelium-cmbse/mycelium-bloom) | The web application where engineers create, explore and edit SysML v2 models. |
| 🕸️ [**Fabric**](https://github.com/mycelium-cmbse/mycelium-fabric) | The SysML v2 back end that stores, versions and serves models. |
| 🔨 [**Forge**](https://github.com/mycelium-cmbse/mycelium-forge) | The package registry for MBSE artefacts: publish, discover and reuse SysML v2, KerML, ECSS-E-TM-10-25 and Capella libraries. |
| 🧵 [**Hypha**](https://github.com/mycelium-cmbse/mycelium-hypha) | The AI agent: a Claude Code plugin, VS Code extension and CLI that give grounded answers about the SysML v2 and KerML specifications and validate textual notation. |
| 🧰 [**SDK**](https://github.com/mycelium-cmbse/mycelium-sdk) | The .NET software development kit shared by the Mycelium applications and available to build your own tools. |

### Foundations

- [**model**](https://github.com/mycelium-cmbse/mycelium-model) – the UML 2.5.1 models that Bloom, Fabric and Forge are generated from
- [**design**](https://github.com/mycelium-cmbse/mycelium-design) – the shared design system and CSS for Bloom and Forge
- [**requirements**](https://github.com/mycelium-cmbse/requirements) – the Software System Specification for the ecosystem

## Get involved

Mycelium is developed in the open. Browse the repositories, open an issue with a question or idea, or send a pull request. Each repository's README explains how to build and run it.
